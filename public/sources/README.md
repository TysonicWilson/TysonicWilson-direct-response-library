# Sources

This directory is a placeholder for the original source PDFs referenced by each
breakdown's `source` frontmatter field (e.g. scans/collections such as
"100 Greatest Sales Letters", the AWAI Direct Response Hall of Fame, and
"World's Greatest Direct Mail Sales Letters").

The original PDFs are **not included** in this repository, for two reasons:

1. **Size** — the combined source PDFs are large and not suited to version control.
2. **Copyright** — these are third-party copyrighted works used here only as the
   basis for the analytical breakdowns; redistributing the original scans is out
   of scope for this project.

If/when source PDFs are added to this app, they would live here and be referenced
from the `source` field already present in `corpus/library-index.json` /
each breakdown's frontmatter.
